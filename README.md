# Suli Anime — v1 (نسخة قابلة للعب، لاعب واحد)

لعبة اجتماعية ثلاثية الأبعاد في المتصفح (Three.js). تطبيق ويب ستاتيكي —
لا خادم خلفي، لا موارد خارجية (Three.js وGLTFLoader منسوخان محلياً).

## التشغيل محلياً

```bash
cd ~/workspace/suli-anime
python3 -m http.server 8137
```

ثم افتح في المتصفح (أو على الآيفون عبر نفس الشبكة بعنوان IP الجهاز):

```
http://localhost:8137/
```

> ملاحظة: لا تفتح `index.html` مباشرة من القرص (`file://`) — وحدات ES
> تحتاج خادم HTTP.

## التحكم

| الإدخال | الفعل |
|---|---|
| العصا الافتراضية (أسفل الشاشة) | المشي في القرية والمنزل |
| النقر على الأرض | المشي إلى النقطة المنقورة (مثل KUM3D) |
| WASD / الأسهم (لوحة مفاتيح) | المشي |
| شريط التنقل السفلي | التبديل بين الشاشات |

## الشاشات

- **الرئيسية**: ترحيب + معاينة حية لكايتو (النموذج الحقيقي الذي صنعه المستخدم في VRoid) يدور ببطء، مع أزرار دخول.
- **القرية**: قرية ساكورا ثلاثية الأبعاد قابلة للمشي — بيوت خشبية، فوانيس، أشجار ساكورا. كايتو يمشي بمشية إجرائية (تأرجح الساقين والذراعين)، والكاميرا تتبعه من الخلف. يوسف وسارة وليان واقفون كشخصيات ثابتة مع أسمائهم.
- **المنزل**: غرفة كايتو بأثاثها، نفس التحكم بحدود أصغر، والكاميرا ثابتة
  من جهة الغرفة المفتوحة (زاوية عرض داخلية تتابع اللاعب بنظرها) لأن الغرفة
  بلا جدارين، فكاميرا المتابعة كانت ستخرج للسماء.
- **مصمم الشخصية**: اختيار الشخصية (كايتو VRM حقيقي، والثلاثة الآخرون مبنيون بالكود)، تبويبات الشعر/الوجه/العينان/الجسم/الملابس/البشرة، منزلق الطول يغيّر حجم المعاينة، زر «جسم رياضي»، وحفظ محلي في `localStorage`.
- **السينما**: هيكل «قريباً» فقط في v1.
- **حسابي**: عرض بيانات كايتو الثابتة (الاسم، المستوى 5، 1,250 عملة).

## بنية الملفات

```
index.html          صفحة واحدة SPA (كل الشاشات + شريط التنقل)
css/style.css       تصميم D1 (كريمي #FBF3E2، ساكورا #D96C8A)، RTL، هاتف أولاً
js/main.js          مدير الشاشات + شاشات الرئيسية/القرية/المنزل/المصمّم
js/env.js           بيئات Three.js (القرية/المنزل/المنصة) + تحميل VRM
js/player.js        اللاعب: مشية إجرائية + كاميرا تتبع + إدخال (عصا/نقر/كيبورد)
js/characters-v4.js الشخصيات الثلاث المبنية بالكود (يوسف/سارة/ليان)
vendor/             three.module.js (0.160.0) + GLTFLoader.js (محلي)
utils/              BufferGeometryUtils.js (يعتمد عليه GLTFLoader)
models/dero.vrm     كايتو — النموذج الحقيقي (VRM 0.x، مواد unlit)
tools/test.js       اختبار ذاتي بـ Playwright (لقطات في proofs/)
proofs/             لقطات الاختبار
```

## ملاحظات تقنية

- النموذج بلا رسوم حركة جاهزة: المشي إجرائي بالكامل (تدوير عظام
  `J_Bip_L/R_UpperLeg` و`LowerLeg` و`UpperArm` + اهتزاز الورك).
- حلقة تصيير واحدة تعمل في كل لحظة: عند تبديل الشاشة تتوقف حلقة الشاشة
  السابقة. مواقع اللاعب محفوظة عند العودة.
- النموذج يواجه ‎−Z‎ افتراضياً؛ إصلاح وضع T: دوران الذراعين `z = ±1.25`.
- السينما واللعب الجماعي والمحادثة ليست في v1 — الشاشات المعنية تقول ذلك
  صراحة بدل أزرار ميتة.
